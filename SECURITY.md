# Security Policy

## Reporting a vulnerability

Please email **security@formstead.dev**. Do not open a public GitHub issue, discussion, or pull request for a security report.

Include:

- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- the plugin version, WordPress version, and PHP version

We acknowledge reports within **three business days**. After that we send a status update at least every seven days until the issue is resolved or declined.

Please keep the report private until we publish a fix or confirm that the report is not a vulnerability.

## Supported versions

Security fixes apply to the latest release. Older tags are not patched.

## Scope

Formstead is a WordPress plugin. Reports that require a compromised WordPress administrator account, a misconfigured host, or third-party plugins are out of scope unless they show a distinct Formstead defect.

The design of the current plugin is described in [docs/threat-model.md](docs/threat-model.md).
